# MONOQLO 対局スケジュール作成ツール

MONOQLO麻雀部 チーム戦(イベント戦)の、対局の組み合わせと席順を作るページ(`index.html`)を置くリポジトリ。

大会CSV作成ツール(event-create)で出力したCSVを読み込み、リーグごとの対局数を入れると、偏りが小さい組み合わせと席順を作って、CSVで出力する。

## 使い方

1. 「CSVファイルを選ぶ」で、大会CSV(例: `20261001.csv`)を読み込む。チームとリーグ構成が読み込まれる。
2. リーグごとに、**1チームの対局数** を入れる。右に、回戦の数と卓の数が出る。
3. 「スケジュールを作る」を押す。リーグごとの組み合わせと席順が表示される。
4. 気に入らなければ「別の組み合わせで作り直す」を押す。押すたびに違う組み合わせになる。
5. 「CSVを出力」を押すと、CSVファイルが保存される。

表は「チーム別」と「回戦別」を切り替えられる。出力するCSVは、どちらの表示でも同じ。

## 対局数の決まり

- 1回戦では、4チームずつ卓に分かれる。チーム数が4で割り切れないときは、余ったチームがその回戦は抜け番になる。
- 全チームを同じ対局数にするため、チーム数によっては入れられる対局数が限られる。
  - チーム数が4の倍数(4・8・12・16…): いくつでもよい
  - チーム数が偶数で4の倍数でない(6・10・14…): 2の倍数
  - チーム数が奇数(5・7・9…): 4の倍数
- 入れられない対局数のときは、理由が表示され、スケジュールは作られない。

## 2次以降のリーグ

2次以降のリーグは、進むチームがまだ決まっていない。そのため「予選1位」「予選2位」のような **順位の枠** で組み合わせを作る。前のリーグが終わったら、順位に合わせてチームを当てはめる。

## 偏りを小さくする内容

- **同卓する回数**: どの2チームも、同じ卓になる回数ができるだけ同じになるようにする。
- **席(東南西北)**: どのチームも、4つの席に座る回数ができるだけ同じになるようにする。対局数が4の倍数なら全席が同じ回数、そうでなければ差は1まで。
- **抜け番**: 対局数は全チーム同じ。対局数の少ないチームから順に打つ。

組み合わせは、入れ替えを何十万回も試して偏りを減らす方法で作る。必ず理論上の最良になるとは限らないが、結果の偏りはリーグごとに画面に表示される(同卓する回数の最少と最多、席の回数の差)。

## 出力するCSV

1行が1チーム。ファイル名は、読み込んだ大会CSVに合わせて `20261001-schedule.csv` のようになる。

```
大会名,リーグ,チーム,対局数,第1戦,第2戦,第3戦
第一回フォーサムリーグ,予選,ネコババしちゃ,12,B卓 南,B卓 南,C卓 東
第一回フォーサムリーグ,予選,なつフェス,12,A卓 南,A卓 北,B卓 南
第一回フォーサムリーグ,セミファイナル,予選1位,8,A卓 西,A卓 南,B卓 東
```

- 各回戦の欄は「卓 席」。同じ回戦で同じ卓の4チームが対局する。抜け番の回戦は `抜け番` と入る。
- 回戦の数はリーグによって違う。少ないリーグは、後ろの欄が空欄になる。
- 文字コードは UTF-8(BOM付き)。Excelでそのまま開ける。
- 日付や時刻は入らない。どの回戦をいつ行うかは、別に決める。
