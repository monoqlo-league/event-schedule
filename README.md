# MONOQLO 対局スケジュール作成ツール

ページ: https://monoqlo-league.github.io/event-schedule/

MONOQLO麻雀部 チーム戦(イベント戦)の、対局の組み合わせと席順を作るページ(`index.html`)を置くリポジトリ。

大会CSV作成ツール(event-create)で出力したCSVを読み込み、リーグごとの対局数と日程を入れると、偏りが小さい組み合わせと席順を作り、回戦ごとに日付を割り当てて、CSVで出力する。

すでにスケジュールのCSVがある大会は、その内容を読み込んで表示し、直して出力し直せる。2次以降のリーグは、日程を「未定」にしておける。

ページのいちばん上に、チーム戦ランキング(event-ranking)へ戻るリンクがある。

## 使い方

1. 「CSVファイルを選ぶ」で、大会CSV(例: `20261001-master.csv`)を読み込む。チームとリーグ構成が読み込まれる。同じ番号のスケジュールのCSVがデータ置き場(event-data)にあれば、続けて読み込まれる(下の「すでにあるスケジュールを直す」)。
2. **1日の試合数** を入れ、**開催曜日** にチェックを入れる(日曜始まりで日〜土が並ぶ)。どちらも全リーグ共通。
3. **卓の名前** を入れる。欄の数は、チーム数を4で割った数(余りは切り捨て)。1つ目から「薔薇」「金木犀」「向日葵」が入っていて、4つ目からは空欄。
4. リーグごとに、**1チームの対局数** と **開始日** を入れる。右に、回戦の数・卓の数・期間が出る。2次以降のリーグで日程が決まっていないものは、開始日の横の **未定** にチェックを入れる。
5. 「スケジュールを作る」(スケジュールのCSVを読み込んであるときは「スケジュールを修正する」)を押す。リーグごとの組み合わせ・席順・日付が表示される。
6. 気に入らなければ「別の組み合わせで作り直す」を押す。押すたびに違う組み合わせになる(日付は変わらない)。
7. 「CSVを出力」を押すと、CSVファイルが保存される。

表は「回戦別」と「チーム別」を切り替えられる。最初は回戦別で表示される。出力するCSVは、どちらの表示でも同じ。

## 対局数の決まり

- 1回戦では、4チームずつ卓に分かれる。チーム数が4で割り切れないときは、余ったチームがその回戦は抜け番になる。
- 全チームを同じ対局数にするため、チーム数によっては入れられる対局数が限られる。
  - チーム数が4の倍数(4・8・12・16…): いくつでもよい
  - チーム数が偶数で4の倍数でない(6・10・14…): 2の倍数
  - チーム数が奇数(5・7・9…): 4の倍数
- 入れられない対局数のときは、理由が表示され、スケジュールは作られない。

## 卓の名前の決まり

- 欄の数は、いちばんチームが多いリーグのチーム数を4で割った数(余りは切り捨て)。12チームなら3つ、16チームなら4つ。
- チームが少ないリーグは、前から順に必要な数だけ使う。12チーム→8チーム→4チームの大会なら、予選は3つ全部、セミファイナルは1つ目と2つ目、ファイナルは1つ目だけ。
- 名前は12文字まで。次のときはエラーになり、スケジュールは作られない。
  - 空欄がある。
  - 同じ名前が2つある。
  - 「/」を含む、または「抜け番」という名前。
- 別の大会CSVに差し替えても、入れた名前は残る。
- 画面では、名前のあとに「卓」を付けて表示する(「薔薇」→「薔薇卓」)。「卓」で終わる名前を入れた場合は、そのまま表示する。CSVには入力した名前だけが入る。
- 入力した順(1つ目・2つ目…)が、卓の並び順になる。CSVの「卓」の列にこの順で入り、ランキングページもこの順に並べる。

## 日程の決まり

- **1日の試合数** は、1日に行う回戦の数。1回戦では全部の卓が同時に打つので、1チームが1日に打つ数と同じになる(抜け番の回戦を除く)。
- 開始日から、開催曜日にあたる日だけを順に拾い、1日の試合数ずつ回戦を割り当てる。最後の日は、残った回戦だけになることがある。
- 開始日の曜日が、開催曜日にチェックされていないときはエラーになる。
- あるリーグの最終日が、次のリーグの開始日と同じ日か、それより後になるときはエラーになる。
- どれかが満たされないときは、理由が表示され、スケジュールは作られない。

例: 12チーム・24局ずつ・1日2試合・月水土・開始日 2026-09-05 → 24回戦を12日間(9/5(土)〜9/30(水))で行う。1日あたり6局。

## 2次以降のリーグ

2次以降のリーグは、進むチームがまだ決まっていない。そのため「予選1位」「予選2位」のような **順位の枠** で組み合わせを作る。前のリーグが終わったら、順位に合わせてチームを当てはめる。

## 日程が未定のリーグ

- 2次以降のリーグには、開始日の横に **未定** のチェックがある。1次リーグにはない。
- チェックを入れると、そのリーグの対局数と開始日の欄は使えなくなる。そのリーグのスケジュールは作らず、出力するCSVにも入れない。
- 未定のリーグは、前後のリーグとの日付の検査(最終日と開始日の前後)から外す。
- ランキングページでは、スケジュールのCSVに入っていないリーグは、スケジュールのCSVがない大会と同じ扱いになる(終わったかどうかを判断しない、終わった対局の結果だけを出す)。
- 日程が決まったら、下の「すでにあるスケジュールを直す」の手順で読み込み直し、チェックを外して対局数と開始日を入れ、出力し直す。ほかのリーグの組み合わせは変わらない。

## すでにあるスケジュールを直す

大会CSVを読み込むと、同じ番号のスケジュールのCSV(`20261001-master.csv` なら `20261001-schedule.csv`)を、データ置き場(event-data)から探す。あれば読み込んで、入力欄と表に出す。

- 読み込まれるもの: 1日の試合数、開催曜日、卓の名前、リーグごとの対局数・開始日・組み合わせ・席・日付。
- スケジュールのCSVに入っていない2次以降のリーグは、「未定」にチェックが入る。
- 読み込むと、大会CSVと同じ形で「20261001-schedule.csv を読み込んだ。予選24局・セミファイナル16局。」のように表示される。
- 読み込んだ組み合わせは、ボタンを押さなくても、すぐ下に表で表示される(画面もそこまで移動する)。
- スケジュールのCSVを読み込んであるあいだ、ボタンの文言は「スケジュールを作る」から **「スケジュールを修正する」** に変わる。入力を直してから押すと、表が作り直される。
- 読み込むのは、データ置き場にあるCSVだけ。手元のスケジュールCSVを選んで読み込むことはできない。
- データ置き場に上げた直後は、古い内容が読み込まれることがある(最長5分ほど)。そのときは、少し待ってから大会CSVを読み込み直す。

読み込んだリーグは、**組み合わせと席をそのまま使う。** 入力を変えたときの動きは次のとおり。

| 変えたもの | 組み合わせ・席 | 日付 |
|---|---|---|
| 何も変えない | そのまま | そのまま(読み込んだ日付) |
| 開始日・開催曜日・1日の試合数 | そのまま | 入力に合わせて割り当て直す |
| 卓の名前 | そのまま(名前だけ変わる) | そのまま |
| 1チームの対局数 | そのリーグだけ作り直す | 入力に合わせて割り当てる |
| 「組み合わせを作り直す」にチェック | そのリーグだけ作り直す | 入力に合わせて割り当てる |
| 「未定」にチェック | CSVに入れない | — |

- 何も変えずに出力すると、読み込んだCSVと同じ内容になる。
- 開催曜日・1日の試合数は全リーグ共通なので、変えると、読み込んだ全リーグの日付が割り当て直される。
- 「別の組み合わせで作り直す」のボタンは、作り直すリーグがあるときだけ出る。読み込んだままのリーグは変わらない。
- 表の見出しに「読み込んだ組み合わせ」と出ているリーグが、そのまま使っているリーグ。
- 特定の回戦だけ組み合わせを入れ替えるような、こまかい手直しはできない。必要なときは、出力したCSVを直接書き換える。
- すでに終わった対局は、ランキングページが対局記録を優先して表示する。スケジュールのCSVを直しても、終わった対局の表示は変わらない。

### 終了したリーグ

スケジュールのCSVといっしょに、対局記録(`20261001-games1.csv` など)もデータ置き場から読む。対局記録の数が、スケジュールにあるそのリーグの対局の数に届いていれば、そのリーグは **終了** とする(ランキングページと同じ判断)。

- 終了したリーグは、対局数と開始日の欄に読み込んだ内容が入り、入力できない。「未定」と「組み合わせを作り直す」のチェックも出ない。行に「終了」と出る。
- 開催曜日・1日の試合数を変えても、終了したリーグは変わらない。組み合わせ・席・日付も、CSVの「開催曜日」「1日の試合数」の列も、読み込んだまま出力する。
- 卓の名前は全リーグ共通なので、変えると終了したリーグの卓の名前も変わる。
- 次のリーグの開始日は、終了したリーグの最終日より後でなければならない。
- 対局記録がまだないリーグ、途中のリーグは、これまでどおり直せる。

### 終了したリーグの次のリーグ

前のリーグが終了していれば、次のリーグの表には、「予選1位」のような順位の枠ではなく、**結果のチーム名** を入れて表示する。

- 順位は、大会CSV(プレイヤーIDとチーム、持ち越しの割合)と対局記録から、ランキングページと同じ計算で出す。合計PTの高い順。2次以降のリーグは、前のリーグから持ち越したPTを足す。同点は、前のリーグの順位が上のほうを上にする。
- 表示だけを変える。**出力するCSVには、枠(「予選1位」)のまま入れる。** ランキングページが、枠をチーム名に置き換えて表示する。
- 前のリーグが終了していないリーグは、これまでどおり枠で表示する。
- 組み合わせを作り直したときも、チーム名で表示する。

次のときは、そのリーグを読み込まない(エラーの理由が表示される)。新しく作ることになる。

- リーグのチーム(2次以降は順位の枠)が、大会CSVと合わない。
- 同じ回戦・同じ卓・同じ席に、チームが2つある。4チームそろっていない卓がある。
- チームによって対局数が違う。

## 偏りを小さくする内容

- **同卓する回数**: どの2チームも、同じ卓になる回数ができるだけ同じになるようにする。
- **席(東南西北)**: どのチームも、4つの席に座る回数ができるだけ同じになるようにする。対局数が4の倍数なら全席が同じ回数、そうでなければ差は1まで。
- **抜け番**: 対局数は全チーム同じ。対局数の少ないチームから順に打つ。

組み合わせは、入れ替えを何十万回も試して偏りを減らす方法で作る。必ず理論上の最良になるとは限らないが、結果の偏りはリーグごとに画面に表示される(同卓する回数の最少と最多、席の回数の差)。

## 出力するCSV

1行が1チーム。ファイル名は、読み込んだ大会CSVに合わせて決まる。`20261001-master.csv` を読み込めば `20261001-schedule.csv` になる。

```
大会名,リーグ,チーム,対局数,開始日,開催曜日,1日の試合数,卓,第1戦,第2戦,第3戦
第一回フォーサムリーグ,予選,ネコババしちゃ,24,2026-09-05,月水土,2,薔薇/金木犀/向日葵,2026-09-05(土) 金木犀 東,2026-09-05(土) 薔薇 北,2026-09-07(月) 向日葵 東
第一回フォーサムリーグ,予選,なつフェス,24,2026-09-05,月水土,2,薔薇/金木犀/向日葵,2026-09-05(土) 薔薇 南,2026-09-05(土) 薔薇 北,2026-09-07(月) 金木犀 南
第一回フォーサムリーグ,セミファイナル,予選1位,8,2026-10-03,月水土,2,薔薇/金木犀,2026-10-03(土) 薔薇 西,2026-10-03(土) 薔薇 南,2026-10-05(月) 金木犀 東
```

- `開始日` はそのリーグの開始日(`YYYY-MM-DD`)。`開催曜日` は選んだ曜日を日曜始まりで並べたもの(例: `月水土`)。`1日の試合数` は入力した数。
- `卓` は、そのリーグで使う卓の名前を、入力した順に「/」でつないだもの。ランキングページは、この順に卓を並べる。
- 各回戦の欄は「日付(曜日) 卓の名前 席」。同じ回戦で同じ卓の4チームが対局する。抜け番の回戦は `2026-09-05(土) 抜け番` のように入る。
- 回戦の数はリーグによって違う。少ないリーグは、後ろの欄が空欄になる。
- 日程が未定のリーグは、行を出さない。
- 文字コードは UTF-8(BOM付き)。Excelでそのまま開ける。
- 時刻は入らない。
